# Cap-Project

*JUDUL*
Analisis Diabetes pada Ibu Hamil: Jumlah Kasus, Hubungan Kehamilan, dan Faktor Usia

*Project Overview*
Tujuan dari analisis ini untuk menganalisis risiko diabetes pada ibu hamil menggunakan dataset diabetes dari Kaggle. Analisis difokuskan pada tiga aspek utama: prevalensi diabetes pada ibu hamil, hubungan antara jumlah kehamilan dengan risiko diabetes, serta perbandingan prevalensi diabetes pada kelompok usia muda dan tua. dari analisis ini diharapkan dapat diperoleh gambaran faktor risiko yang memengaruhi kemungkinan ibu hamil mengalami diabetes.

*Raw dataset*
https://www.kaggle.com/datasets/mathchi/diabetes-data-set 

*AI support explanationAI support explanation*
Membuat semua visualisasi data menggunakan IBM Granite. Setelah setiap grafik jadi, saya memanfaatkan sebuah AI generatif sebagai rekan diskusi untuk menganalisis maknanya lebih dalam.
AI membantu memberikan perspektif awal dan mempercepat penyusunan draf kesimpulan. Namun, semua interpretasi akhir dan keputusan strategis dalam laporan ini sepenuhnya saya tentukan sendiri.

*Insight&Findings*
Risiko diabetes meningkat tajam seiring bertambahnya usia dan jumlah kehamilan.
Kedua faktor ini memiliki efek kumulatif. Profil risiko tertinggi adalah wanita di usia paruh baya yang telah hamil beberapa kali, menjadikan periode ini paling kritis untuk intervensi.

Meskipun ada profil risiko yang jelas, jumlah wanita tanpa diabetes di dalam data lebih banyak.
Ini menunjukkan bahwa faktor-faktor tersebut meningkatkan kemungkinan (risiko), bukan sebuah kepastian diagnosis.
